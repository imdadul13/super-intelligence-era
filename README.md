# SUPER INTELLIGENCE ERA — $SIE

A premium editorial landing page for an unofficial Solana community / meme project. Built with React, TypeScript, and Vite; deployable to Vercel as a static frontend.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Community configuration

Edit the constants at the top of `src/App.tsx` when official links and a contract are ready:

- `CONTRACT_ADDRESS`
- `PUMPFUN_URL`
- `X_URL`
- `TELEGRAM_URL`

Until configured, community references use safe on-page placeholders and no fake contract address is displayed. Archive and intelligence data are clearly labeled demo/placeholder content.
